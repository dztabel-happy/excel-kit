# 只改指定假设并返回结果的完整上游

确认每个要改的假设确实是所求结果上游的输入单元格，只改这些单元格，只重算所求结果，并返回每个结果的上游公式、链条末端的输入单元格及其取值，以及修改前后的工作簿版本。

## 运行

在本目录下依次执行：

1. `excel-kit script request.json`：生成 `cost-model-updated.xlsx`。

`request.json` 里的路径相对本目录。脚本本体是 `recipe.js`，开头的注释列出了全部参数。

## 参数

`assumptions` 是要改的输入；`results` 是要重算并解释的结果单元格。

## 样本与许可

`sample/cost-model.xlsx` 是用公开操作合成的小型造价模型，不依据任何真实文件，建造请求是 `sample/build-model.request.json`。仓库内的测试另用用户提供的真实工程表做了一个额外用例，该文件没有再分发许可，不随包发布。

## 样本上的结果

设计费率由 3% 改为 3.5%：总投资 59,251,500 → 59,535,000，单方指标 4,937.625 → 4,961.25；两个结果的上游输入都是假设表的 5 个单元格。

## 要点

- 不在任何所求结果上游的"假设"、或者本身是公式的单元格，在改动之前就被拒绝。
- 只按目标重算，未涉及的公式缓存按产品规则失效，不会冒充本次结果。
- 上游按公式里写明的静态引用追溯。`INDIRECT`、`OFFSET` 这类在运行时才决定的来源不在其中；依赖查询会在 `limitations` 里用 `RUNTIME_REFERENCES_PENDING` 指出这样的公式。
