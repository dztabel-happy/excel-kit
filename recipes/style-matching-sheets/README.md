# 对名称匹配的工作表批量设置格式、打印与视图

对名称匹配正则表达式的每张工作表应用同一组格式、冻结窗格、打印设置与视图，每张表一步，并报告处理了哪些表、没动哪些表。

## 运行

在本目录下依次执行：

1. `excel-kit script request.json`：生成 `report-tables-styled.xlsx`。

`request.json` 里的路径相对本目录。脚本本体是 `recipe.js`，开头的注释列出了全部参数。

## 参数

`pattern` 是表名的正则；`format`、`freeze`、`print`、`view` 是要应用的设置；`expectSheets` 是应当匹配的表数，用来防止正则写错。

## 样本与许可

`sample/report-tables.xlsx` 是用公开操作合成的 7 张表的工作簿，不依据任何真实文件，建造请求是 `sample/build-workbook.request.json`。仓库内的测试另用用户提供的 30 张表的真实工程表做了一个额外用例，该文件不随包发布。

## 样本上的结果

`^表2\.\d+ ` 匹配 3 张表：表头加粗反白、金额列两位小数、冻结首行、A4 横向并重复首行、缩放 90% 且不显示网格线；其余 4 张表不变，跨表合计仍为 811.5。

## 要点

- 格式类步骤不改变数值，用 `calculation:{mode:"none"}` 省去计算。
- 任一张表设置失败（例如受保护）则整体失败：只设置了一半的报表不如不设置。
