# 滚动到下一期间

复制最新的期间工作表，填入新期间数据，修改共用假设，在汇总表登记新期间，然后刷新工作簿里全部图表、迷你图与透视，使它们不再显示旧数。

## 运行

在本目录下依次执行：

1. `excel-kit run prepare.json`：在预算模板上加一个图表、一组迷你图和一个透视，生成 `sample/budget-with-objects.xlsx`。
2. `excel-kit script request.json`：生成 `budget-2026-02.xlsx`。

`request.json` 里的路径相对本目录。脚本本体是 `recipe.js`，开头的注释列出了全部参数。

## 参数

`source`、`target` 是被复制与新建的工作表；`updates` 写到新表；`assumptions` 是共用输入；`summary` 是汇总表新增的一行，可含公式。

## 样本与许可

`sample/budget-template.xlsx` 是本仓库第三阶段用 XlsxWriter 合成的预算模板，不是第三方文件，可再分发。模板自带的图表引用固定数据，所以图表、迷你图与透视由 `prepare.json` 用公开操作加上，来源指向期间区块。

## 样本上的结果

新期间数量 5、1、10，税率由 9% 改为 10%：新表不含税金额 62.5、20、52.5，合计 135，税额合计 13.5；原期间税额变为 3.75、4、2.1；透视随之重建；两张期间表的图表缓存分别是各自的金额。

## 要点

- 来源发生变化的透视必须在改动它的同一步里刷新，否则该步以 `PIVOT_REFRESH_REQUIRED` 失败。配方因此先清点透视，再把刷新与编辑放在同一步。
- 目标工作表已存在时拒绝执行，避免重复滚动。
- 工作表复制会带上图表、迷你图、打印设置和表内名称；Table 与透视不随表复制。
