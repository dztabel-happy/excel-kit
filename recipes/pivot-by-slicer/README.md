# 追加明细、刷新透视，按切片器逐项读取下游公式

向明细 Table 追加记录并刷新透视，然后按切片器的每个选项逐一选择，读取依赖透视结果的公式在每种选择下的值，最后清除选择并核对各项之和等于总计。

## 运行

在本目录下依次执行：

1. `excel-kit run prepare.json`：合成明细 Table、透视、切片器和两条下游公式，生成 `sales.xlsx`。
2. `excel-kit script request.json`：生成 `sales-updated.xlsx`。

`request.json` 里的路径相对本目录。脚本本体是 `recipe.js`，开头的注释列出了全部参数。

## 参数

`append` 是要追加的记录；`pivot`、`slicer` 指向对象；`items` 是要逐项选择的切片器选项；`read` 是下游单元格；`total` 指明哪个读取项可以跨选项相加，用于一致性核对。

## 样本与许可

样本完全由 `prepare.json` 用公开操作合成，没有外部来源。

## 样本上的结果

追加两条记录后，华东 150（泵 100）、华北 95（泵 70）、华南 70（泵 40），不筛选时总计 315（泵 210）。

## 要点

- 依赖透视结果的公式只在刷新该透视的那一步里计算：更早步骤留下的透视结果不会被当作当前值，之后的只读计算会得到 `PIVOT_RESULT_UNAVAILABLE`。所以每次选择都用该步自带的 `read` 读取。
- `items` 漏掉一个选项时，各项之和对不上总计，配方拒绝发布。
- 下游公式直接用整列引用读透视结果（`INDEX(透视!B:B, MATCH("总计", 透视!A:A, 0))`），透视行数变化时不必改范围。
