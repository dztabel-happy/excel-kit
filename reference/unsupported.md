# 不支持的情形

程序明确不支持什么，遇到时怎样交付、怎样向用户说明。找出具体是哪些格见 [audit.md](audit.md)；函数层面的限制与 Excel 的已知差异见 [function-limits.md](function-limits.md)；一个函数是否受支持查 `help fn.<函数名>`。

## 总的做法

先分清三件事：Excel 的错误值是计算所得；计算不可得是没有本次结果；保存被拒是没有发布（见 [calculation.md](calculation.md)）。

遇到下面的情形，不要绕过，也不要用文件里的存值冒充本次结果。要么用 `targets` 只交付不受影响的部分，要么停下来向用户说明，并写清需要用户在 Excel 里完成的事项。

它们让本次需要的公式不可得时，`all/targets` 默认仍保存可靠结果并给逐格清单；`requireCompleteCalculation:true` 才拒绝。操作自己需要的当前值不可得仍拒绝。只是存在而不影响本次计算的不在此列：工作簿只含 VBA 工程而没有公式依赖它，或有口令保护但本次操作没有触及。不依赖它们的结果可以用 `targets` 计算并采信，但报告里不能说"整本已完整重算"，也不要笼统地说"源文件有错"，按具体原因分别说明。

## 不支持的情形

- **VBA 不执行**：XLSM 可以编辑，VBA 工程原样保留，另存时扩展名保持 `.xlsm`。工作簿自带的 VBA 自定义函数报告 `UNSUPPORTED_FUNCTION`；定义名称里的 Excel 4 宏表函数（如 `GET.WORKBOOK`）同样不可得。依赖它们的格需要在 Excel 中启用宏后重算。
- **加密文件不编辑**：请用户提供解除加密的副本，不要尝试破解。
- **模拟运算表（dataTable）不重算**：程序原样保留它，表内结果和依赖它的本次计算都不可得；默认 `all` 仍发布其他可靠结果；不受支持的区域编辑或位移会被整体拒绝。改了它的输入之后，文件里留着的仍是旧的存值，见 [deliverable.md](deliverable.md)。用 `targets` 计算不依赖它的结果，并告诉用户运算表要在 Excel 里重算。
- **透视表不自动刷新**：依赖它的公式按保存的透视结果计算（与 Excel 重算不刷新透视相同），透视本身不算本次刷新；缓存设了打开时刷新的透视，依赖它的公式不可得，见 [pivots.md](pivots.md)。
- **外部工作簿引用不读取、不改写**：依赖它的结果不可得；只有已无任何使用的链接可以删除，见 [external-links.md](external-links.md)。
- **迭代计算不支持**：真实循环报告 `CIRCULAR_REFERENCE`，不按工作簿的迭代设置求解。
- **部分函数没有公开计算入口**：统计函数 `WEIBULL`、`F.INV`、`F.INV.RT`、`FINV`、`BINOM.INV`、`CRITBINOM` 仍不支持，直接调用报告 `UNSUPPORTED_FUNCTION`，受影响下游的诊断为 `INCOMPLETE_DEPENDENCY`；`WEIBULL.DIST` 与旧名 `WEIBULL` 的支持状态不同。完整入口以 `capabilities` 为准。
- **保留公式不等于支持计算**：`TRIMRANGE` 等公式及泰语辅助函数（如 `THAIDIGIT`、`THAINUMSTRING`）可以保留原生存储写法，但仍没有公开计算支持，不能把它们写成总会返回某个 Excel 错误的函数。
- **联合多区域引用**（如 `(A1:A3,C1:C3)` 或定义为多块区域的名称）可用于已支持的汇总与顺序统计参数；`AREAS` 也支持按区域项计数，重复、重叠和相邻区域不合并。其他不支持的位置报告 `UNSUPPORTED_UNION_REFERENCE`，不能从一个入口可用推断所有函数都支持联合引用。
- **整列 `XLOOKUP`／`XMATCH`**：空白查找值可能落到数据末行之后时会被拒绝。
- **省略引用的 `CELL`** 按公式所在格解释，与 Excel 的"最后改动格"不同；需要读取自身值的选择器会被拒绝。
- **口令保护**：不猜测、不移除校验，带口令的保护需要用户自行解除，见 [protection.md](protection.md)。
- **规模**：约百万公式级的整本计算可能超过期限的上限，见 [cost.md](cost.md)。

## 核对的是什么

保存时的核对是写出的文件与内存一致，不是与 Excel 一致。函数有公开入口，不代表所有参数组合都能计算或与 Excel 逐值相同。
