# 外部工作簿引用与外部链接

公式引用别的工作簿时程序怎样处理、怎样向用户说明、怎样删除不再使用的外部链接。参数查 `help externalLink.delete`。

## 程序怎样处理外部引用

- 依赖外部工作簿的公式报告 `EXTERNAL_REFERENCE`，并列出文件里存储的来源。
- 程序不读取外部文件，也不把文件里存的外部缓存值当作本次输入，所以依赖它的本次结果不可得；`all` 默认仍发布其他可靠结果，并列出不可得位置。显式 `requireCompleteCalculation:true` 才拒绝。
- 程序不改写外部引用。
- 只引用外部工作簿固定地址的公式，在与它无关的本地编辑之后保留文件里的存值（读取时标 `cache`），不是本次结果；规则见 [deliverable.md](deliverable.md)。

`inspect` 的 `workbook.externalLinks` 列出工作簿里的外部链接。

## 怎么办

- 向用户说明依赖哪些外部来源。
- 只对不依赖外部来源的结果用 `targets` 计算（见 [calculation.md](calculation.md)），交付件里其余公式没有值或只有历史保存值的，在报告里说明。
- 需要这些值时，请用户提供把外部链接转成值的版本；或按用户要求把公式改为引用本工作簿。

## 删除不再使用的外部链接

公式都改完、某个外部链接已经没有任何使用时，用 `externalLink.delete` 删除它：参数是 `index`，可选 `target`，对照 `inspect` 的 `workbook.externalLinks` 取值。登记、关系、部件与内容类型一并删除。

```json
{ "op": "externalLink.delete", "index": 1 }
```

（片段：只示意操作的形状，它和其他操作一样写进请求的 `operations` 数组。）

删不掉时：

- 链接仍被单元格公式、名称、条件格式、数据验证、Table 列公式、图表公式、形状或表单控件的单元格链接使用时，报 `EXTERNAL_LINK_IN_USE`，并列出使用处。先按细节把使用处改掉，再删除。
- 删除会让后面仍在使用的链接改变序号时，报 `EXTERNAL_LINK_RENUMBERING`。换一个删除次序。
- 无法按 XML 解析的旧式 VML 绘图部件里，任何 `[n]`（包括注释和普通文字里的）都算作使用，这时可能保守地拒绝删除。
- 仍删不掉的，请用户在 Excel 里断开链接。

## 从另一份工作簿迁入可独立工作的区块

用 `help range.transfer` 查看矩形、图表与映射契约。先定位来源，再为区外引用和名称逐个选择目标绑定；两簿同名的定义可以指向不同输入。将变换后的公式与系列落点纳入核对。非空目标须根据预检确认的精确矩形、当前目标版本授权。会话里可用试算预检未保存版本。遇到跨区对象时缩小范围或选择整表导入。
